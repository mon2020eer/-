# دليل الترخيص وإدارة الاشتراكات

هذا الدليل **لمالك البرنامج وحده** — لا يُوزَّع مع التطبيق ولا يُطلع عليه العملاء.
يشرح كيف يعمل نظام الاشتراك، وكيف تُصدر المفاتيح وتديرها وتتابع التجديدات.

---

## 1. كيف يعمل النظام باختصار

التطبيق يعمل على جهاز العميل بلا إنترنت، فلا يمكن الاعتماد على خادم يتحقّق من
الاشتراك. الحلّ: **مفتاح موقَّع رقمياً** يحمل داخله كل ما يحتاجه التطبيق.

```
CR-<الحمولة>.<التوقيع>

الحمولة (JSON مضغوط ومُرمَّز): {
    "id":      "رقم الترخيص",
    "office":  "اسم المكتب",
    "tier":    "basic أو pro",
    "machine": "بصمة جهاز العميل",
    "issued":  "تاريخ الإصدار",
    "expires": "تاريخ الانتهاء"
}
```

- **التوقيع Ed25519**: المفتاح الخاص عندك وحدك، والتطبيق يحمل المفتاح العام فقط.
  فلا يستطيع أحد توليد مفتاح صالح ولو فكّك التطبيق كلّه وقرأ شيفرته سطراً سطراً.
- **تعديل حرف واحد** في المفتاح — أو في تاريخ الانتهاء داخله — يُبطله فوراً،
  لأن التوقيع لا يعود مطابقاً للحمولة.
- **جهاز واحد**: بصمة الجهاز داخل الحمولة، فالمفتاح لا يعمل على غيره.
- **الانتهاء**: تاريخ داخل الحمولة الموقَّعة، يُقارَن بتاريخ الجهاز عند كل تشغيل.

## 2. الإعداد مرّة واحدة قبل أول بيع

### الخطوة ١: ولّد زوج المفاتيح

</div>

```bash
python tools/license_tool.py --init
```

<div dir="rtl">

يطبع الأمر المفتاح العام، ويحفظ المفتاح الخاص في:

```
~/.car_rental_license_private.key
```

### الخطوة ٢: ضع المفتاح العام في التطبيق

افتح `app/core/licensing.py` وضع القيمة المطبوعة مكان:

</div>

```python
PUBLIC_KEY_B64 = "REPLACE_WITH_YOUR_PUBLIC_KEY"
```

<div dir="rtl">

> بدون هذه الخطوة يرفض التطبيق **كل** مفتاح ويقول صراحةً إن نسخة البرنامج لم
> يُوضع فيها مفتاح التوقيع — وهي رسالة تشخيص مقصودة لك لا لغموض على العميل.

### الخطوة ٣: أعد بناء ملف التشغيل

</div>

```powershell
.\build\build_exe.ps1
```

## 3. ⚠ المفتاح الخاص هو رأس مالك

| افعل | لا تفعل |
|---|---|
| احفظ نسخة منه على وسيط خارجي (فلاشة في مكان آمن) | لا تضعه في المستودع ولا في مجلد مشترك |
| احتفظ بنسخة ثانية في مكان مختلف عن الأولى | لا ترسله في واتساب ولا بريد ولا لأي جهة |
| قيّد صلاحيات ملفه (تفعل الأداة ذلك تلقائياً) | لا تنسخه إلى جهاز العميل ولا إلى جهاز مشترك |

**من يملك مفتاحك الخاص يولّد اشتراكات مجانية للأبد.**

**وإن ضاع منك:** المفاتيح الصادرة تبقى صالحة حتى انتهائها، لكنك لن تستطيع إصدار
مفتاح جديد. العلاج الوحيد: توليد زوج جديد، وبناء نسخة جديدة من التطبيق، وإعادة
إصدار المفاتيح لكل عملائك. لذلك النسخة الاحتياطية ليست ترفاً.

## 4. دورة البيع: من الطلب إلى التفعيل

```
العميل يشغّل البرنامج  →  يختار نسخة  →  تجربة ٧ أيام كاملة
                                              ↓
                          يقرّر الاشتراك ويحوّل المبلغ
                                              ↓
              يضغط «نسخ» على بصمة جهازه ويرسلها لك في واتساب
                                              ↓
              تولّد المفتاح بأمر واحد وترسله  →  يلصقه  →  يعمل
```

### الخطوة ١: العميل يرسل لك بصمة جهازه

تظهر البصمة في شاشة التفعيل وفي صفحة «الاشتراك» داخل التطبيق، بجانبها زرّ
«نسخ». شكلها أربع مجموعات تُقرأ وتُملى بالهاتف عند الحاجة:

```
15CC-64D5-DC91-F0A7
```

### الخطوة ٢: تولّد المفتاح

</div>

```bash
python tools/license_tool.py \
    --office "مكتب النور لإيجار السيارات" \
    --tier basic \
    --months 1 \
    --machine 15CC-64D5-DC91-F0A7 \
    --note "دفع تحويل مصرفي 2026-09-15"
```

<div dir="rtl">

| الخيار | معناه |
|---|---|
| `--office` | اسم المكتب — يظهر للعميل في صفحة الاشتراك ويُحفظ في سجلّك |
| `--tier` | `basic` أو `pro` |
| `--months` | عدد الأشهر (الشهر = ٣٠ يوماً: بسيط ومفهوم ولا يحتاج تقويماً) |
| `--days` | عدد أيام صريح بدل الأشهر — للتمديد أو للتعويض عن انقطاع |
| `--machine` | بصمة جهاز العميل كما أرسلها |
| `--note` | ملاحظة تُحفظ في سجلّك: طريقة الدفع، رقم التحويل، أي شيء |

يطبع الأمر بطاقة ملخّص ثم المفتاح. **أرسل المفتاح كما هو** — سطر واحد بلا فراغات
مضافة ولا كسر أسطر.

### الخطوة ٣: العميل يلصق المفتاح

شاشة التفعيل ← «تفعيل الاشتراك». يعمل البرنامج فوراً بلا إعادة تشغيل.

## 5. المتابعة اليومية

### سجلّ كل ما أصدرت

كل مفتاح يُسجَّل تلقائياً في `tools/issued_licenses.jsonl` (سطر JSON لكل إصدار).
هذا السجلّ هو دفتر اشتراكاتك: منه تعرف من اشترك، ومتى، وبأي نسخة، ومتى ينتهي.

> الملف مستثنى من المستودع في `.gitignore` لأنه يحتوي مفاتيح صالحة وبيانات عملاء.
> خذ منه نسخة احتياطية مع مفتاحك الخاص.

### من ينتهي اشتراكه قريباً؟

</div>

```bash
python tools/license_tool.py --renewals 7
```

<div dir="rtl">

يطبع الاشتراكات المنتهية خلال ٧ أيام (أو العدد الذي تكتبه). شغّله صباح كل أحد
وذكّر أصحابها قبل أن يتوقّف البرنامج عندهم — التذكير المسبق يمنع مكالمة غاضبة،
ويرفع نسبة التجديد أكثر من أي شيء آخر.

### التحقّق من مفتاح

</div>

```bash
python tools/license_tool.py --verify CR-xxxx.yyyy --machine 15CC-64D5-DC91-F0A7
```

<div dir="rtl">

يفحصه بالضبط كما يفحصه التطبيق. استعمله حين يقول عميل إن مفتاحه «لا يعمل»:
سترى بنفسك أهو منتهٍ، أم لجهاز آخر، أم نُسخ ناقصاً.

### التجديد

نفس أمر الإصدار ببصمة الجهاز نفسها. المفتاح الجديد يحلّ محلّ القديم، والتاريخ
يبدأ من يوم الإصدار.

### نقل الترخيص إلى جهاز آخر

1. العميل يفتح صفحة «الاشتراك» ← «نقل الترخيص إلى جهاز آخر» (يحذف المفتاح من
   الجهاز القديم).
2. يشغّل البرنامج على الجهاز الجديد ويرسل لك بصمته.
3. تصدر له مفتاحاً جديداً بالمدّة المتبقّية عبر `--days`.

## 6. ما يفعله التطبيق عند كل تشغيل

1. يقرأ المفتاح المحفوظ من إعدادات قاعدة البيانات.
2. يتحقّق من التوقيع، ثم من بصمة الجهاز، ثم من تاريخ الانتهاء — **بهذا الترتيب**،
   لأن الحمولة غير موثوقة قبل التحقّق من توقيعها.
3. يقارن تاريخ اليوم بآخر تاريخ شُوهد؛ فإن كان اليوم **أسبق** بأكثر من يوم فقد
   أُرجعت ساعة الجهاز عمداً ← يُقفل البرنامج ويطلب مفتاحاً جديداً.
4. يثبّت مزايا النسخة على التطبيق كلّه، فتُفرض في **طبقة الخدمة** لا بإخفاء
   الأزرار وحدها.

### وضع القفل

عند انتهاء الاشتراك أو التجربة:

| متاح | ممنوع |
|---|---|
| ✅ عرض كل البيانات والبحث فيها | ❌ إنشاء عقد جديد |
| ✅ طباعة العقود القائمة PDF | ❌ تسجيل دفعة |
| ✅ **نسخة احتياطية كاملة من البيانات** | ❌ إضافة سيارة أو عميل |

**لماذا تبقى البيانات متاحة؟** حجز بيانات مكتب عن صاحبه يُفقدك سمعتك في سوق صغير
تنتقل فيه الأخبار بسرعة، وقد يُعرّضك لمشكلة قانونية. ومنع العمل الجديد ضغط كافٍ
تماماً: مكتب لا يستطيع إصدار عقد اليوم سيدفع اليوم.

## 7. مصارحة لازمة عن حدود الحماية

أي تطبيق سطح مكتب يعمل على جهاز العميل **قابل للكسر** بمن يملك المهارة والوقت،
وتطبيق بايثون محزوم بـ PyInstaller أسهل من غيره. ما يحميك عملياً ثلاثة أشياء:

1. **التوقيع يمنع توليد المفاتيح.** الكسر الوحيد الممكن هو تعديل البرنامج نفسه،
   وهو عمل مبرمج لا عمل مستخدم.
2. **حجم السوق.** لا أحد يستأجر مبرمجاً ليكسر برنامجاً بـ ١٢٠ د.ل شهرياً.
3. **التحديثات والدعم.** النسخة المكسورة لا تحصل عليهما، وهي الحماية الحقيقية.

فلا تستثمر في تعقيد الأقفال أكثر من هذا. المال يُنفق في المزايا لا في الأقفال.

## 8. مشكلات شائعة وحلولها

| ما يقوله العميل | السبب غالباً | الحلّ |
|---|---|---|
| «المفتاح غير صالح أو مُعدَّل» | نُسخ ناقصاً أو دخله سطر جديد | يعيد النسخ كاملاً بسطر واحد |
| «هذا المفتاح صادر لجهاز آخر» | أُصدر لبصمة مختلفة | تحقّق من البصمة وأعد الإصدار |
| «انتهى اشتراكك بتاريخ …» | فعلاً انتهى | جدّد بأمر الإصدار نفسه |
| «تاريخ الجهاز غير صحيح» | ساعة الجهاز أُرجعت | يضبط تاريخ ويندوز ثم يعيد التشغيل؛ إن استمرّ أصدر مفتاحاً جديداً |
| «لم يُوضع مفتاح التوقيع في هذه النسخة» | نسخة بُنيت قبل وضع المفتاح العام | أعد البناء بعد الخطوة ٢ وأرسل ملف التشغيل |

## 9. أوامر سريعة

</div>

```bash
# بصمة هذا الجهاز
python tools/license_tool.py --machine-id

# اشتراك شهر — النسخة الأساسية
python tools/license_tool.py --office "مكتب النور" --tier basic --months 1 --machine <البصمة>

# اشتراك سنة — النسخة المتقدّمة (ادفع ١٠ خذ ١٢ = ٣٦٠ يوماً)
python tools/license_tool.py --office "مكتب النور" --tier pro --days 360 --machine <البصمة>

# تمديد أسبوع مجاناً (تعويض عن انقطاع أو مجاملة)
python tools/license_tool.py --office "مكتب النور" --tier pro --days 7 --machine <البصمة>

# من ينتهي اشتراكه خلال ١٠ أيام
python tools/license_tool.py --renewals 10

# فحص مفتاح
python tools/license_tool.py --verify CR-... --machine <البصمة>
```
