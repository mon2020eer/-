# 🚗 منظومة إدارة مكتب إيجار السيارات

تطبيق **سطح مكتب لويندوز** بواجهة عربية كاملة من اليمين إلى اليسار، يدير العملاء
والسيارات وعقود الإيجار والمدفوعات، ويحفظ نسخة احتياطية يومية تلقائية من قاعدة
البيانات في **Google Drive**.

يعمل **دون إنترنت** بالكامل؛ الإنترنت مطلوب فقط لرفع النسخة الاحتياطية.

---

## ✨ ما تقدّمه المنظومة

| الوحدة | التفصيل |
|---|---|
| **الدخول والصلاحيات** | كلمات مرور مُعمّاة بـ PBKDF2-HMAC-SHA256، صلاحيتان: مدير وموظّف، قفل الحساب بعد ٥ محاولات فاشلة |
| **العملاء** | الاسم والهاتف ورقم الجواز/الوطني ورخصة القيادة وتاريخ انتهائها، مرفقات الوثائق، قائمة سوداء |
| **السيارات** | الماركة والموديل وسنة الصنع واللوحة واللون والتعرفة اليومية والأسبوعية، وحالة كل سيارة (متاحة/مؤجَّرة/في الصيانة) |
| **العقود** | حساب تلقائي للقيمة، عربون ودفعات جزئية، تمديد، إغلاق بإعادة حساب المدّة الفعلية، إلغاء، **طباعة العقد PDF بالعربية** |
| **الدفعات** | سجلّ دفعات مستقلّ لكل عقد، وحالة الدفع محسوبة اشتقاقاً لا يدوياً |
| **الصيانة والمخالفات** | إدخال السيارة للصيانة وإخراجها، تكاليف، وتسجيل المخالفات المرورية وربطها بالعقد المسؤول |
| **لوحة المعلومات** | بطاقات لحظية: المتاح والمؤجَّر ونسبة الإشغال وإيراد الشهر والمستحقّات، وبحث سريع باللوحة أو الاسم |
| **التقارير** | إيرادات الفترة، أداء كل سيارة، أفضل العملاء، كشف الديون، تصدير CSV يفتحه Excel بالعربية |
| **العملات** | دينار ليبي ودولار ويورو، وكل عقد يحتفظ بسعر الصرف وقت إنشائه |
| **النسخ الاحتياطي** | رفع يومي تلقائي إلى Google Drive، نسخ يدوي، استعادة أي نسخة، سجلّ لكل المحاولات |
| **سجلّ التدقيق** | من فعل ماذا ومتى: دخول، إضافة، تعديل، حذف، دفعات، نسخ احتياطي |

## 🚀 التشغيل السريع (للمطوّر)

```bash
cd car_rental
python -m pip install -r requirements.txt
python -m app
```

بيانات الدخول الأولى: المستخدم `admin` وكلمة المرور `admin123`
— ويُلزمك التطبيق بتغييرها فور أول دخول.

### أوامر إضافية

```bash
python -m app --version        # رقم الإصدار
python -m app --self-test      # فحص ذاتي بلا شاشة (للبناء والاختبار)
python -m app --backup-now     # نسخة احتياطية من سطر الأوامر
python -m app --data-dir PATH  # تشغيل على مجلد بيانات مختلف
```

### الاختبارات

```bash
QT_QPA_PLATFORM=offscreen python -m pytest tests -q
```

## 📦 بناء ملف التشغيل (.exe)

```powershell
powershell -ExecutionPolicy Bypass -File build\build_exe.ps1
```

أو نزّله جاهزاً من **GitHub Actions ← منظومة إيجار السيارات ← المخرجات**
دون الحاجة إلى جهاز ويندوز. التفاصيل كاملةً في
[`docs/BUILD_WINDOWS.md`](docs/BUILD_WINDOWS.md).

## 🗂️ أين تُحفظ البيانات؟

```
ويندوز : %APPDATA%\CarRentalOffice\
لينكس  : ~/.local/share/CarRentalOffice/
```

| الملف | المحتوى |
|---|---|
| `car_rental.db` | قاعدة البيانات (كل شيء) |
| `attachments/` | نسخ وثائق العملاء |
| `exports/` | عقود PDF وملفات CSV المصدَّرة |
| `backups/` | النسخ المحلية قبل الرفع |
| `credentials.json` | بيانات اعتماد Google (تضعها أنت) |
| `token.json` | رمز ربط حساب Google (يُنشأ تلقائياً) |

> ⚠️ **لا تشارك `credentials.json` ولا `token.json` مع أحد ولا ترفعهما إلى GitHub.**
> كلاهما مستثنى في `.gitignore` منذ أول إيداع.

## 🧱 البنية

```
car_rental/
├─ app/
│  ├─ core/          قاعدة البيانات، التعمية، الجلسة، المال، سجلّ التدقيق
│  ├─ repositories/  قراءة وكتابة الكيانات
│  ├─ services/      التسعير، العقود، التقارير، PDF، النسخ الاحتياطي
│  └─ ui/            واجهة PyQt6 العربية (RTL)
├─ tests/            ٧٢ اختباراً: منطق + تكامل + فحص واجهة
├─ build/            ملف PyInstaller وسكربت البناء ومثبّت Inno Setup
└─ docs/             الأدلّة العربية
```

**قاعدة الاتجاه:** الطبقة الأعلى تستدعي الأدنى فقط — فيبقى منطق العمل كلّه
قابلاً للاختبار بلا واجهة رسومية.

## 🛡️ ضمانات جوهرية مبنيّة في المنظومة

1. **استحالة الحجز المزدوج**: فهرس فريد جزئي في SQLite نفسها يمنع وجود عقدين
   مفتوحين لسيارة واحدة، فلا يمكن لأي خطأ برمجي أو واجهة تخطّيه.
2. **لا أخطاء تقريب مالية**: كل المبالغ أعداد صحيحة بالوحدة الصغرى، لا فاصلة عائمة.
3. **تقارير تاريخية ثابتة**: كل عقد يحفظ تعرفته وسعر صرفه، فتعديل الأسعار اليوم
   لا يغيّر تقارير الشهر الماضي.
4. **حالة دفع لا تكذب**: تُحسب من مجموع الدفعات المسجَّلة، ولا تُخزَّن يدوياً.
5. **نسخ احتياطي سليم**: يُنتَج عبر واجهة `sqlite3.backup()` الرسمية ويُفحص بـ
   `PRAGMA integrity_check` قبل الرفع وقبل الاستعادة.
