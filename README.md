# 🛫 مراقب مناقصات السفر والسياحة — منصة العطاءات الحكومية الليبية

أداة آلية تفحص **منصة العطاءات الحكومية** ([attaat.pm.gov.ly](https://www.attaat.pm.gov.ly/))
يومياً، وترشّح الإعلانات المتعلّقة بنشاط السفر والسياحة، ثم ترسل تنبيهاً فورياً
إلى هاتفك عبر **تيليجرام** يتضمّن عنوان الإعلان وتاريخه ورابطه المباشر.

**التكلفة الإجمالية: صفر.** لا خادم، ولا اشتراك، ولا حاجة لإبقاء حاسوبك يعمل.

---

| البند | التفصيل |

| التنبيه | بوت تيليجرام على هاتفك |
| منع التكرار | ملف حالة `state/seen.json` يُودَع تلقائياً بعد كل تشغيل |
| التكلفة | مجاني بالكامل ضمن الحدود المجانية |

## ⚠️ ملاحظة معمارية جوهرية (تستحق القراءة)

الطلب الأصلي كان استخدام `requests` و`BeautifulSoup` لتحليل صفحة الموقع.
غير أنّ الفحص الفعلي للمنصة أظهر أنّها **تطبيق Angular أحادي الصفحة (SPA)**؛
فمصدر الصفحة الأوّلي لا يحتوي على أي بيانات مناقصات إطلاقاً، بل على وسم واحد فقط:

```html
<body><app-root></app-root><script src="main.…js"></script></body>
```

**النتيجة:** تحليل صفحة HTML بـ BeautifulSoup وحدها كان سيُرجع **صفر نتائج دائماً**.

ولذلك جرى تتبّع حزمة الجافاسكربت الخاصة بالمنصة واستخراج الواجهة الحقيقية التي
يستدعيها التطبيق نفسه لعرض الإعلانات:

```
POST https://www.attaat.pm.gov.ly/back_api/api/PublicAttaat
{"sortBy":"publishDate","sortOrder":"desc","pageNumber":0,"pageSize":50,
 "biddingTypeId":0,"governmentalEntityId":0}

← {"count": 157, "list": [ … ]}
```

وهذا المسار **أدقّ وأثبت** من تحليل HTML، لأنّه يُرجع بيانات منظّمة (عنوان، جهة،
تاريخ نشر، آخر موعد، مرفقات) ولا يتأثّر بأي تغيير في شكل الموقع.

أمّا `BeautifulSoup` فتُستخدم في الأداة في موضعين حقيقيين لا تجميليّين:
1. **الاكتشاف التلقائي لمسار الواجهة** من حزمة الجافاسكربت، فتظلّ الأداة عاملة
   إذا غيّرت المنصة بصمة الملف أو مسار الواجهة الخلفية.
2. **تنظيف أي وسوم HTML** قد ترد داخل عنوان الإعلان أو نصّه.

## 🧠 الميزة الأهم: مطابقة عربية دقيقة، لا مطابقة حرفية ساذجة

المطابقة الحرفية المباشرة تُنتج **إنذارات كاذبة** كثيرة في العربية. وقد رُصدت
هذه الحالات فعلياً في بيانات المنصة الحيّة:

| الإعلان الحقيقي | المطابقة الساذجة | السبب | سلوك هذه الأداة |
|---|---|---|---|
| «التعاقد في مجال **السفرجة** والنظافة» | ✅ تُطابق «سفر» | «السفرجة» خدمات ضيافة، لا سفر | ❌ **مرفوضة** |
| «توريد وتركيب خزانات وقود» | ✅ تُطابق «طيران» | اسم الجهة: «الجهاز التنفيذي **للطيران**» | ❌ **مرفوضة** |
| «توريد معدات الصيانة» | ✅ تُطابق «سياحة» | اسم الجهة: «وزارة **السياحة**» | ❌ **مرفوضة** |
| «مطلوب **تداكر سفر** الى الفلبين» | ⚠️ قد تفوتها | «تداكر» خطأ إملائي شائع | ✅ **مقبولة** |

آليات المعالجة الثلاث:

**1) التطبيع (Normalization)** — توحيد `أ إ آ ← ا` و`ى ← ي` و`ة ← ه`، وحذف
التشكيل والتطويل. بذلك تتطابق «تأشيرات» مع «تاشيرات» تلقائياً.

**2) المطابقة الصرفية** — يُقسَّم النص إلى كلمات، وتُقبل الكلمة فقط إذا ساوت
الجذر أو الجذر مع سابقة/لاحقة عربية معروفة. فتُقبل «للسفر» و«والسياحة»،
وتُرفض «السفرجة» لأنّ «جة» ليست لاحقة صحيحة.

**3) تحييد اسم الجهة المُعلِنة** — يُحذف اسم الجهة من نصّ الإعلان قبل المطابقة،
كي لا تُحتسب كلمة «طيران» في اسم الجهة موضوعاً للمناقصة.

**نتيجة الاختبار على 157 إعلاناً حقيقياً:** المطابقة الساذجة أعطت 9 نتائج،
منها 6 خاطئة. هذه الأداة أعطت **3 نتائج، جميعها صحيحة**.

# 🚀 دليل النشر خطوة بخطوة (من هاتفك بالكامل)

## الجزء الأول: إنشاء بوت تيليجرام عبر BotFather

**الخطوة 1 — افتح تيليجرام على هاتفك** وابحث في الأعلى عن: `@BotFather`
واختر الحساب الذي يحمل **علامة التوثيق الزرقاء**، ثم اضغط **Start**.

**الخطوة 2 — أنشئ البوت.** أرسل الأمر:
```
/newbot
```
سيطلب منك أمرين بالترتيب:
- **اسم البوت** (حرّ، مثال): `مناقصات السفر والسياحة`
- **معرّف البوت**: يجب أن ينتهي بـ `bot`، مثال: `libya_travel_tenders_bot`
  (إن كان محجوزاً فجرّب اسماً آخر).

**الخطوة 3 — احفظ الرمز.** سيرد BotFather برسالة تحتوي سطراً مثل:
```
123456789:AAHdqTcvCH1vGWJxfSeofSAs0K5PALDsaw
```
هذا هو **`TELEGRAM_BOT_TOKEN`**.

> 🔐 **تحذير أمني:** هذا الرمز يعادل كلمة مرور البوت. لا تنشره في أي مكان عام
> ولا تكتبه داخل ملفات المشروع. سنضعه في «الأسرار المشفّرة» في الخطوة 8.
> إن تسرّب منك، أرسل `/revoke` لـ BotFather للحصول على رمز جديد.

**الخطوة 4 — فعّل المحادثة.** ابحث عن معرّف بوتك (مثل `@libya_travel_tenders_bot`)،
افتح المحادثة، واضغط **Start**. هذه الخطوة **إلزامية** — تيليجرام يمنع البوتات
من مراسلتك قبل أن تبدأ أنت المحادثة.

**الخطوة 5 — احصل على رقم المحادثة `chat_id`.** افتح متصفّح هاتفك على العنوان
التالي بعد استبدال `<الرمز>` برمز بوتك:
```
https://api.telegram.org/bot<الرمز>/getUpdates
```
ابحث في النتيجة عن:
```json
"chat":{"id":987654321,"first_name":"…"}
```
الرقم `987654321` هو **`TELEGRAM_CHAT_ID`**.

> 💡 إن ظهرت النتيجة فارغة `{"ok":true,"result":[]}` فأرسل أي رسالة للبوت
> (مثل «مرحبا») ثم حدّث الصفحة.
>
> 🛠 بديل: بعد نشر المشروع يمكنك تشغيل `python main.py --chat-id` وستعرض
> الأداة الرقم مباشرة.

## الجزء الثاني: النشر والجدولة مجاناً على GitHub Actions

**الخطوة 6 — أنشئ المستودع.** من متصفّح هاتفك ادخل [github.com](https://github.com)
(أنشئ حساباً مجانياً إن لم يكن لديك)، ثم **New repository**:
- الاسم: `libya-tenders-watcher`
- اختر **Private** (خاص) — كافٍ تماماً ضمن الباقة المجانية.

**الخطوة 7 — ارفع ملفات المشروع.** أسهل طريقة من الهاتف هي زر
**Add file ← Create new file** لكل ملف، مع الانتباه إلى كتابة المسار كاملاً
في خانة الاسم لإنشاء المجلدات تلقائياً، مثل:
```
tender_watcher/arabic.py
.github/workflows/tenders.yml
```

**الخطوة 8 — أضف الأسرار المشفّرة.** من صفحة المستودع:
```
Settings ← Secrets and variables ← Actions ← New repository secret
```
أضف سرّين اثنين:

| الاسم | القيمة |
|---|---|
| `TELEGRAM_BOT_TOKEN` | الرمز من الخطوة 3 |
| `TELEGRAM_CHAT_ID` | الرقم من الخطوة 5 |

> 🔐 هذه القيم تُخزَّن مشفّرة، ولا تظهر في سجلّات التشغيل، ولا يمكن لأحد
> قراءتها بعد حفظها — حتى أنت.

**الخطوة 9 — امنح صلاحية الكتابة.** هذه الخطوة ضرورية كي يتمكّن التشغيل
الآلي من حفظ ملف الحالة الذي يمنع تكرار التنبيهات:
```
Settings ← Actions ← General ← Workflow permissions
← اختر: Read and write permissions ← Save
```

**الخطوة 10 — شغّل الأداة يدوياً أول مرة.** من تبويب **Actions**:
```
Actions ← «مراقبة مناقصات السفر والسياحة» ← Run workflow
```
خلال دقيقة تقريباً ستصلك على هاتفك رسالة تأكيد التفعيل، تليها أحدث الإعلانات
المطابقة. وبعدها ستعمل الأداة **تلقائياً كل يوم** دون أي تدخّل منك.

# ⚙️ التخصيص

## تعديل الكلمات المفتاحية

**الطريقة الأولى (الأسهل من الهاتف):** بدون تعديل أي ملف —
```
Settings ← Secrets and variables ← Actions ← تبويب Variables ← New variable
الاسم: KEYWORDS
القيمة: تذاكر,سفر,سياح,فنادق,طيران,تاشير,حجز,مطار
```

**الطريقة الثانية:** حرّر ملف `keywords.json` مباشرة.

> 📝 **قاعدة مهمة:** اكتب الكلمات **جذوراً مجرّدة** من «ال» التعريف.
> اكتب `سفر` لا `السفر`، و`سياح` لا `السياحة` — والأداة تتكفّل تلقائياً
> بكل الصيغ: السفر، للسفر، والسفر، سياحية، السياحة…

## ضبط دقّة الترشيح

يُحسب لكل إعلان **وزن مطابقة**: كل كلمة في العنوان = 3 نقاط، وكل كلمة في
نصّ الإعلان = نقطة واحدة. ويُرسَل التنبيه عند بلوغ `MIN_SCORE` (افتراضياً 2).

| القيمة | الأثر |
|---|---|
| `MIN_SCORE=1` | ترشيح واسع — تنبيهات أكثر واحتمال إنذارات كاذبة أعلى |
| `MIN_SCORE=2` | **الافتراضي الموصى به** — مطابقة واحدة في العنوان تكفي |
| `MIN_SCORE=3` | ترشيح متشدّد — مطابقات العنوان القوية فقط |

## تغيير موعد التشغيل

في ملف `.github/workflows/tenders.yml` — التوقيت بـ **UTC**، وليبيا **UTC+2**:
```yaml
- cron: "0 5 * * *"    # 07:00 بتوقيت ليبيا
- cron: "0 6 * * *"    # 08:00 بتوقيت ليبيا
- cron: "0 5,13 * * *" # مرّتين يومياً: 07:00 و 15:00
```

# 🔧 استكشاف الأخطاء

| العطل | السبب المرجّح | الحلّ |
|---|---|---|
| لا تصل أي رسالة | لم تضغط **Start** في محادثة البوت | افتح البوت واضغط Start (الخطوة 4) |
| `chat not found` | `TELEGRAM_CHAT_ID` خاطئ | أعد استخراجه عبر `--chat-id` |
| `Unauthorized` | الرمز خاطئ أو مُلغى | أنشئ رمزاً جديداً عبر `/revoke` |
| فشل خطوة «إيداع ملف الحالة» | صلاحية الكتابة غير مفعّلة | نفّذ الخطوة 9 |
| تنبيهات مكرّرة | ملف الحالة لا يُحفَظ | تأكّد من نجاح خطوة الإيداع |
| تنبيهات غير ذات صلة | الترشيح واسع | ارفع `MIN_SCORE` إلى 3 |
| فاتتني مناقصة | كلمة مفتاحية ناقصة | أضفها إلى `KEYWORDS` |

# 📋 ملاحظات تشغيلية مهمّة

**1) دقّة موعد التشغيل.** جدولة GitHub Actions **ليست مضمونة بالدقيقة**؛ فقد
يتأخّر التشغيل من دقائق إلى نحو ساعة في أوقات الذروة. هذا سلوك طبيعي ولا
يؤثّر على النتيجة، إذ تُقارَن الإعلانات بالمعرّف لا بالوقت.

**2) تعطيل الجدولة بعد 60 يوماً.** توقف GitHub الجدولة تلقائياً في المستودعات
التي لا نشاط فيها لمدة 60 يوماً، وترسل لك تنبيهاً بالبريد قبل ذلك. وإيداع ملف
الحالة اليومي يقلّل احتمال حدوث ذلك. وفي حال توقّفها، يكفي الضغط على
**Run workflow** مرّة واحدة لإعادة تفعيلها.

**3) التشغيل الأول.** لن تصلك دفعة ضخمة من الأرشيف؛ إذ ترسل الأداة ملخّصاً
وأحدث 5 إعلانات مطابقة فقط، ثم تنبّهك بالجديد فقط بعد ذلك.

**4) هذه أداة رصد لا أداة تقديم عروض.** تنبّهك الأداة بالإعلان وتمنحك رابطه
المباشر، ويبقى تقديم العرض واستيفاء الشروط القانونية عبر المنصة الرسمية.

**5) احترام المنصة.** تُرسِل الأداة طلباً واحداً يومياً على الواجهة العامة
نفسها التي يستخدمها الموقع، وهو حِمل لا يُذكر ولا يضرّ بالخدمة.
